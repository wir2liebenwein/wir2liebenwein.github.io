Die Wiener Agentur Heimat hat sich etwas ganz Besonderes einfallen lassen: sie geben drei von Judith Becks Weinen eine Stimme – so spricht der Wein sprichwörtlich für sich. Das **Reben.Reden-Set** beinhaltet folgende Weine:

**Koreaa 2017** (gemischter Satz, vogelwild)

**Pet Nat Bambule! P 2018** (aus Pinot Noir Trauben)

**Judith 2015** (100% Blaufränkisch)

Das Besondere an diesem Reben.Reden-Set ist, dass es **zu jedem Wein einen kleinen Geschichte gibt**. Die Etiketten wurden mit einem speziellen Code gestaltet.

Und so funktioniert es: Zuerst auf dem Smartphone **rebenreden.at** öffnen, dann das Etikett scannen und dann der kleinen Geschichte lauschen.

Wir haben ein paar dieser limitierten Reben.Reden-Sets ergattern können. Wir verpacken euch die drei Weine in einer schönen Faltschachtel. Das etwas andere Geschenk für Wein- und Designliebhaber. Reben.Reden-Preis: 75 EUR

Und so kommt ihr an das Reben.Reden-Set: ihr schreibt uns eine [**Email**](mailto:info@wir2liebenwein.de?subject=Reben.Reden.Set) oder ruft uns an und **wir liefern euch** das Set oder die Weine **kostenlos (Stadtgebiet München)**, oder ihr holt es bei uns ab. Für alle, die nicht in München wohnen: wir verschicken das Reben.Reden-Set sowie alle Weine auch per dpd.

**Cheers! & lasst die Reben Reden**
